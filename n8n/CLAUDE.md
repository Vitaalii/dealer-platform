## Жёсткие правила

- ⚠️ **`[TEST]` впереди боя (решение владельца 2026-10-09).** `[TEST] AI Agent v3.0`
  — описание `finalize_deal` без мандата (`effa014`); `[TEST] Tool: Resolver Core`
  — без `client_mode` / `client_signal` (`f2de42d`). На бою — прежние. Прогоны на
  `[TEST]`, затрагивающие финализацию и резолвер, **не равны боевому
  поведению** — выводы о бое по ним не делать. `[TEST]` к бою не возвращать;
  выкатка — только по плану 2026-10-09-003 и условию handoff §9.3.

- **Прогоны на `[TEST]`-контуре — без `deal_id`.** Контур совпадает с продом по
  всем code-нодам и читает те же таблицы NocoDB, а за его callback-адресом стоит
  дев-бот с доступом к боевому Bitrix. Пустой `deal_id` — единственное, что
  отсекает запись в CRM. Дилер `99`, `user_id` с префиксом `test-`. Перед
  выводами по прогону — проверить в исполнении, что `deal_id` действительно
  пуст (2026-10-03 дев-бот прислал строку «None» вместо пустого). Вебхуки
  [TEST]-контура с 2026-10-03 требуют `X-N8N-Secret` (тестовый секрет), без
  него — 403. Подробности — в solution про изоляцию.
- **Чтение NocoDB — бережно:** только нужные поля (`fields=`), страницы не
  больше 25 записей, пауза между страницами; без массовых чтений архива
  диалогов и таблиц стока (3,7–30,8 тыс. строк). Нужен срез — точечный
  фильтр (`where=`) по дилеру / модели.
- **Запись в живые таблицы NocoDB** — только скриптом по протоколу
  `apply_*.py`: срез «до» → dry-run → снапшот → проверка отката → `--apply` →
  сверка чтением.
- **Запись воркфлоу в n8n через API** (правило владельца 2026-09-30): разрешена
  для `[TEST]`-копий и новых воркфлоу; **боевые — только по отдельной команде
  владельца**, с бэкапом, diff после записи и заранее описанным откатом.
  Инструмент — `flow/cabinet-web-entry/api/apply_workflow_patch.py` (проверка
  «до», diff, наборы `*-rollback`). `binaryMode` API не принимает: при
  изменении существующего воркфлоу сервер сохраняет прежнее значение, у
  созданных через API его нет (для JSON-воркфлоу на результат не влияет —
  проверено 2026-09-30). Запись в активный воркфлоу сразу становится рабочей
  версией.
- **Sim-тесты** запускать как `node --test flow/lib/*.test.mjs` (запуск по
  каталогу на Node 22 не работает).
- **Исходники = бой.** До и после любой перегенерации воркфлоу —
  `python3 flow/cabinet-web-entry/api/check_sources_vs_live.py` (только чтение
  n8n, код 0). Известные расхождения — только записью в
  `api/expected_divergences.json` с решением владельца, не правкой нормализации.
