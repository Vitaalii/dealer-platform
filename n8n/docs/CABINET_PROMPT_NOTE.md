# Вставка в промпт NocoDB: личный кабинет (U7)

Промпты живут в NocoDB и из кода не правятся — текст ниже нужно вручную добавить
в системный промпт (все сценарии, теги `Prompt_Teg`/`Prompt_Ver`, используемые
дилерами с кабинетом).

## Текст вставки

> Тебе доступны переменные `qualification_context.cabinet_url` (персональная
> ссылка на личный кабинет клиента) и `qualification_context.cabinet_status`
> (`not_visited` / `phone_confirmed` / `form_submitted`). Если клиент не оставил
> телефон и `cabinet_url` заполнена — предложи ему продолжить оформление в
> личном кабинете по этой ссылке (подтвердить номер по коду и заполнить анкету
> онлайн), один раз, ненавязчиво. Если `cabinet_url` пустая или телефон уже
> получен — кабинет не упоминай.

## Дополнение (2026-08-10): сначала комплектация, потом ссылка

Кредитный калькулятор на странице кабинета считает по снапшоту, который бот
замораживает по **выбранной комплектации** из результатов подбора. Если ссылка
выдана до выбора комплектации, снапшота нет — клиент получает кабинет без
калькулятора, с ручным вводом трёх полей (штатная деградация, но потеря главной
функции). В промпт добавить требование:

> Прежде чем предлагать личный кабинет, доведи подбор до выбора конкретной
> комплектации (клиент подтвердил, какая машина его интересует). Ссылку на
> кабинет предлагай только после этого — тогда клиент увидит в кабинете
> кредитный калькулятор по выбранной машине.

## Примечания

- Ссылка выдаётся ботом только клиенту без телефона в чате; при повторных ходах
  переменная содержит тот же URL (выдача идемпотентна, R19).
- `cabinet_status` можно использовать для реплик вида «вижу, вы подтвердили
  номер в кабинете» (`phone_confirmed`) или «анкета получена» (`form_submitted`).
