# chore: выключить активные устаревшие дубли тулов в n8n

## Summary

Три воркфлоу эпохи агента v2 активны, хотя их вызывают только выключенные
агенты. Задача — убедиться, что живых вызывающих нет, и выключить их по команде
владельца. Не выполнялась: оформлена 2026-10-09 по решению владельца.

## Problem Frame

Сверка 2026-10-09 (handoff §9) нашла активные дубли боевых тулов. Пока они
активны, их можно по ошибке подключить вместо боевых — так в базовом JSON Combo
уже стояла ссылка на `ZYVac3Twp_ugyP3Jngwhj` вместо `XCPe53sUwk8i9e3T`.

| Воркфлоу | id | versionId (2026-10-09) | Кто ссылается |
|---|---|---|---|
| `Tool - Car Search` | `qunUsxh-zt4J-gc38lijX` | `9e1e8b6d` (2026-04-27) | выключенные `AI Agent`, `AI Agent v2.0`, `v2.0 MAX`, `v2.0 MAX_test`, бэкапы |
| `Tool: Combo Calculator` | `y4ee1N5dlH1tZyq4` | `95040746` (2026-05-05) | выключенные `AI Agent v2.0`, `v2.0 MAX`, `v2.0 MAX_test` |
| `TOOL: AUTO.RU EVALUATION` | `ZYVac3Twp_ugyP3Jngwhj` | `04374357` (2026-05-05) | дубль Combo `y4ee…` и выключенные агенты v2 |

## Requirements

- R1. Перед выключением — доказательство чтением, что вызовов нет: исполнения
  каждого дубля за доступное окно (~2,5 суток) и ссылки из всех активных воркфлоу.
- R2. Выключение — только по отдельной команде владельца, с бэкапом и
  обратной командой (`POST /workflows/<id>/activate`).
- R3. Воркфлоу не удаляются; выключенные агенты v2 не трогаются.

## Implementation Units

### U1. Проверка отсутствия вызовов

- **Goal:** список активных воркфлоу со ссылками на три id (ожидается пустой) и
  исполнения дублей за окно ретенции.
- **Files:** скрипт в `flow/cabinet-web-entry/api/` (только чтение).
- **Verification:** ссылок из активных воркфлоу нет; исполнений нет или каждое
  объяснено.

### U2. Выключение по команде

- **Goal:** три дубля выключены; бэкап в `flow/backups/<дата>-legacy-duplicates/`.
- **Dependencies:** U1, команда владельца.
- **Verification:** `active=false` у трёх id; `check_sources_vs_live.py` зелёная;
  запись в handoff.
