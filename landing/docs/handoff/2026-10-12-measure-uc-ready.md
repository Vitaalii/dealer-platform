# Замер готовности страницы haval-demo-new — до и после вставки U2 (план 2026-10-12-001)

Цель: проверить из России, что Swiper и иконки с бота не замедлили страницу.
Правило (владелец, 2026-10-12): после не хуже, чем до → U2 на Geely и Belgee; хуже → стоп и решаем (например, бот вторым адресом после cdn).

«Готовность» — момент, когда пришли и Swiper, и каталог: страница ждёт оба и сразу показывает подбор (событие `uc:ready`). Сверено с самим событием 2026-10-12 — расходится на 6–15 мс.

## Подготовка (один раз)

1. Откройте Chrome на компьютере. VPN выключен. Другие вкладки с тяжёлыми загрузками закрыты.
2. Откройте https://demo.autodc.org/haval-demo-new
3. Нажмите F12 (на Mac — Cmd+Option+I).
4. Откройте вкладку **Network**.
5. Поставьте галочку **Disable cache**. Рядом в списке скорости должно стоять **No throttling**.
6. Откройте вкладку **Console**.
7. Вставьте в консоль строку ниже и нажмите Enter (если Chrome просит разрешить вставку — наберите `allow pasting` и Enter, потом вставьте снова):

```
(() => { const r = performance.getEntriesByType('resource'), src = window.UC_SWIPER_SOURCE; if (!src) return 'страница ещё не готова — подождите и повторите'; const end = f => Math.max(0, ...r.filter(f).map(e => e.responseEnd)); const sw = end(e => /swiper-bundle\.min\.js/.test(e.name) && new URL(e.name).hostname === src); const cat = end(e => /\/catalog\//.test(e.name)); return 'готовность ' + Math.round(Math.max(sw, cat)) + ' мс (Swiper ' + Math.round(sw) + ', каталог ' + Math.round(cat) + ', Swiper с ' + src + ')'; })()
```

Ответ — строка вида `готовность 3158 мс (Swiper 1655, каталог 3158, Swiper с cdn.jsdelivr.net)`.

## Один замер

DevTools всё время открыты (иначе «Disable cache» не действует).

1. Перезагрузите страницу: Ctrl+R (на Mac — Cmd+R).
2. Подождите, пока страница полностью покажется, и ещё 5 секунд.
3. Щёлкните в консоли, нажмите стрелку ↑ (вернётся строка замера), затем Enter.
4. Запишите число после «готовность» и адрес после «Swiper с».

## ДО — сейчас, до вставки U2

Сделайте **7 замеров** подряд. В каждом должно быть «Swiper с cdn.jsdelivr.net» — это текущая версия.

## ПОСЛЕ — сразу после вставки U2 на haval-demo-new

Тот же компьютер, та же сеть, по возможности в тот же час. Сначала скажите агенту — он проверит `check-live`. Затем **7 замеров** тем же способом. В каждом должно быть «Swiper с obut-5oaj-5i2u.gw-1a.dockhost.net» — это новая версия. Если стоит `cdn.jsdelivr.net`, страница отдаёт старый U2 или бот не ответил — запишите и скажите агенту.
