## R1. Боты «В чате» — из `GET {бот}/bot-links` по марке дилера

**Сейчас.** `tgBot` / `maxBot` зашиты в наборы «ТЕСТ / БОЙ» U2; боевые — боты Geely/Belgee, поэтому
Haval (haval-demo-new) уходит в бота Geely.

**Факты (2026-10-06, только чтение).**
- Боевой `/bot-links` → 200, `Access-Control-Allow-Origin: *`, без кэш-заголовков:
  `max` [belgee, geely] → `https://max.ru/id781424127394_bot`; `max` [haval] →
  `https://max.ru/id781424127394_2_bot`; `telegram` [belgee, geely] → `https://t.me/vashassistentbot`;
  `telegram` [haval] → `https://t.me/havalconsultantbot`.
- Дев `/bot-links` → `max` ["*"] `…/id781424127394_1_bot`, `telegram` ["*"] `https://t.me/TestmesssBot`.
- Марка дилера — `form_values.brand` настроек: `01` Haval, `02` Geely, `03` Belgee, `99` Haval.

**U2.**
- Запрос `{UC_SITE.botUrl}/bot-links` — параллельно настройкам дилера (заголовок ngrok — как у
  остальных запросов к дев-боту). Новый промис `window._botLinksReady` → `{ telegram, max }`,
  каждое — ссылка или `null`; резолвится, когда пришли и настройки, и `/bot-links`; сбой любого — `null`.
- Выбор: марка = `form_values.brand`, обрезанная, в нижнем регистре; запись канала, где `brands`
  содержит марку, **иначе** запись с `"*"` (точное совпадение важнее «любой»). Несколько точных —
  первая по порядку ответа, предупреждение в консоль.
- Ссылка принимается, только если это `https://t.me/<имя>` / `https://max.ru/<id>` (имя/id —
  `[A-Za-z0-9_]+`); иначе — как нет записи.
- Формат перехода — ровно как сейчас (сверено с кодом U2):
  - Telegram: `tg://resolve?domain=<имя>&start=<payload>`, через 1,5 с при видимой странице —
    `https://t.me/<имя>?start=<payload>`;
  - MAX: `https://max.ru/<id>?start=` + `encodeURIComponent(payload)`;
  - `payload = skuId + '_' + globalModelUtm`. Имя/id берётся из пути `link`.
- Нет ответа или нет записи для марки — `console.error` с маркой и каналом; кнопка канала скрыта.
- `tgBot` / `maxBot` из `UC_SITES` удалить; из защиты сборки (`tools/build-production.mjs`,
  список значений чужого режима) убрать имена ботов — останутся адреса ботов и `/cabinet_dev`.

**U6.**
- Карточки `#uc-ms-tg` / `#uc-ms-max` показываются, только если для канала есть ссылка
  (`_botLinksReady`); до ответа — скрыты. «На сайте» — как сейчас.
- На мобайле (≤ 480 px) «На сайте» сейчас скрыта и по умолчанию выбран MAX: если MAX нет —
  выбрать Telegram; **если нет обоих — см. вопрос В1**.
- Ветка `mySuccessFunction` (U2) берёт ссылку из того же результата; если её вдруг нет — без
  перехода, ошибка в консоль.

## R2. Цвет «ДАЛЕЕ» — на уровне страницы

**Сейчас.** `btnBg` / `btnBgHover` в `UC_SITES`; U2 пишет их в `style` элемента `<html>`;
`:root` в `<style>` U2 — боевой запасной; U3/U6 читают `var(--uc-btn-next-bg, #2D5467)`.

**Предложение — HTML-код страницы в `<head>`** (Tilda: Настройки страницы → Дополнительно →
«HTML-код для вставки внутрь HEAD»):

```html
<style>:root{--uc-btn-next-bg:#2D5467;--uc-btn-next-bg-hover:#3C728D}</style>
```

Почему там: стиль в `<head>` применяется до первой отрисовки (без мигания цвета), не зависит от
блоков и переживает их перевставку; один и тот же механизм на любом сайте. Альтернатива — общий
HEAD сайта (Настройки сайта → Ещё), если цвет один на все страницы сайта.

**U2:** убрать `btnBg`/`btnBgHover` из `UC_SITES`, запись в `<html>` и объявление цвета в `:root`
своего `<style>` — иначе его `:root` (стоит ниже по документу) перебьёт значение из `<head>`.
Запасной цвет остаётся в U3/U6 (`var(…, #2D5467)` / `#3C728D`): страница без кода — тёмно-синяя кнопка.

**Строки для страниц** (значения — как сейчас на странице; задавать обе переменные):

| Страница | Строка в HEAD |
|---|---|
| haval-demo-new | `<style>:root{--uc-btn-next-bg:#2D5467;--uc-btn-next-bg-hover:#3C728D}</style>` (до пилота была бирюзовая `#6ACEC3`/`#5BB0A7` — В2) |
| offer.geely-radar.ru | `<style>:root{--uc-btn-next-bg:#2D5467;--uc-btn-next-bg-hover:#3C728D}</style>` |
| sale.belgee-radar.ru | `<style>:root{--uc-btn-next-bg:#2D5467;--uc-btn-next-bg-hover:#3C728D}</style>` |
| page154296216 (тест) | `<style>:root{--uc-btn-next-bg:#6ACEC3;--uc-btn-next-bg-hover:#5BB0A7}</style>` |

Контраст белого текста: `#2D5467` — 8,15:1 (AAA), наведение `#3C728D` — 5,27:1 (AA); `#6ACEC3` —
1,87:1 и `#5BB0A7` — 2,56:1, ниже AA (так на тестовой странице и раньше). Новый цвет для боевых
страниц — со свежей проверкой контраста.

## R3. `cabinet_page_url` полным адресом на своём хосте

U2 `parseDealerConfig`: принимать путь от корня **или** `https://` с хостом этой страницы
(`location.hostname`); чужой хост, `http:`, `//…` — отбрасывать (как сейчас — запасной путь U6).
U6 `ucLkCabinetPageUrl` уже сверяет путь через `new URL(u, origin)` — без изменений.
Боевой бот отдаёт полные адреса: `01` → `https://demo.autodc.org/cabinet?src=web`, `02` →
`https://offer.geely-radar.ru/cabinet?src=web`, `03` → `https://sale.belgee-radar.ru/cabinet?src=web`.

## R4. Колонка активности каталога — из настроек дилера

Разным дилерам нужен разный набор моделей (на offer.geely-radar.ru владелец вручную заменил
`Active` на `Active_1`; в исходник не переносим).
- U2: новое поле настроек (имя согласует агент бота, рабочее — `catalog_active_field`):
  строка `[A-Za-z0-9_ ]{1,64}`, иначе/пусто — `"Active"`. Фильтр каталога
  (`safelyGetField(item, 'Active')`) — по этому имени; сообщение «Нет активных авто» называет колонку.
- **Порядок выкатки на Geely:** сначала бот отдаёт для `02` значение `Active_1`, потом перевставка
  U2 — иначе фильтр вернётся к `Active` и набор моделей на сайте поменяется.

## Проверки

- **dealer-settings-harness** (U2, обе сборки): `/bot-links` — точная марка; только `"*"`; точная
  и `"*"` вместе (берётся точная); марки нет; 500 / сеть; неверная ссылка; регистр марки
  («Haval» ↔ «haval»). Формат переходов Telegram (deep link + https через 1,5 с) и MAX
  (`encodeURIComponent`). `cabinet_page_url`: путь — принят; `https://` свой хост — принят; чужой
  хост, `http:`, `//` — отброшены. Колонка активности: задана / пусто / мусор → `Active`.
  Цвет: U2 не пишет `style` в `<html>` и не объявляет переменные в `:root`.
- **lk-tab-harness** и **phone-validation-harness** (U6): карточки при наличии/отсутствии каждого
  канала, десктоп и мобайл; выбор по умолчанию на мобайле без MAX; prefetch HTML кабинета по
  полному адресу из настроек.
- `npm run build:prod` → `check:prod`; защита сборки без имён ботов; `npm run test:harness`;
  `npm run test:visual` (цвет в обоих вариантах одинаковый — запасной); новые скриншоты
