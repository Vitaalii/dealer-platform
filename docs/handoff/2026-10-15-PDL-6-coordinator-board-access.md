# Handoff PDL-6: доступ координатора к доске Multica (2026-10-15)

## Что сделано

- Исследование по плану PDL-5 (версия 2 + правки владельца). Отчёт:
  `docs/research/2026-10-coordinator-board-access.md`.
- Изучено: официальная документация Anthropic по пользовательским коннекторам, IP-адресам,
  Claude Code, GitHub в проектах; исходный код `multica-ai/multica` v0.6.2 (коммит `7ab92d76`);
  сторонние MCP-серверы для Multica, код `strider2038/multica-mcp` v0.2.0 (коммит `5fbfc8e1`).
- Главные выводы: в Multica нет токенов и ролей «только чтение»; официального MCP-сервера нет;
  claude.ai требует OAuth или «без входа», статичный токен в заголовке — бета не для всех;
  лучший готовый кандидат — `strider2038/multica-mcp` в режиме только чтения.

## Что проверено и как

- Факты о claude.ai — по страницам claude.com/docs, support.claude.com, platform.claude.com,
  code.claude.com, прочитанным 2026-10-15 (ссылки в отчёте).
- Факты о Multica — чтением кода клонированного тега v0.6.2 (`git clone --depth 1 --branch v0.6.2`),
  пути и строки в отчёте; ключевые (таблица PAT, роли, документация токенов и ролей, маршруты задач,
  почта в списке участников) перепроверены повторно.
- `strider2038/multica-mcp` v0.2.0: регистрация инструментов, пути API, вход по ключу, отсутствие
  `os/exec` — чтением кода и `grep`.
- Ничего не собиралось и не запускалось; к серверу Multica и к claude.ai не подключался.
- Секреты: gitleaks на машине агента не установлен, ставить его агент не вправе. Вместо этого —
  поиск по изменённым файлам шаблонов `mul_[0-9a-f]`, `mat_`, `Bearer [A-Za-z0-9]{20,}`, почтовых
  адресов: совпадений нет. Перед слиянием нужен прогон gitleaks владельцем или агентом с ним.

## Что не проверено

- Доступна ли секция Request headers (статичный токен) на личном тарифе Max.
- Работают ли пользовательские коннекторы в чате внутри проекта на Max (запрета не найдено).
- Действует ли `readOnlyHint` для пользовательских коннекторов.
- Сторонние MCP-серверы, кроме `strider2038`, — только по README и метаданным GitHub.
- Оценки объёма работ и расхода токенов — не измерялись.
