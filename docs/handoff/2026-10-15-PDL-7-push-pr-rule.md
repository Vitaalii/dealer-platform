# PDL-7 — правило push и PR в корневых CLAUDE.md и AGENTS.md

## Что сделано
- В `CLAUDE.md` и `AGENTS.md` (строка 45, раздел «В конце работы») строка
  «Push — только по команде владельца.» заменена на:
  «Push и PR: перевод владельцем задачи-работы в Todo — это команда отправить ветку задачи и открыть PR в main.
  В задаче-плане ничего не отправлять. Отправка в main, слияние PR и force-push — только владелец.»
- Основание: решение владельца в `docs/coordination/COORDINATOR.md`, раздел 8, п. 3, и описание задачи PDL-7.
- Выход из зоны (корневые файлы) — разовое разрешение владельца из описания задачи.

## Что проверено
- `diff CLAUDE.md AGENTS.md` — пусто (файлы одинаковые).
- `git diff --stat main` — по 1 строке изменено в `CLAUDE.md` и `AGENTS.md`, плюс этот файл handoff.

## Что не проверено
- gitleaks перед коммитом не запускался: `which gitleaks` → `gitleaks not found`.

## Открытые вопросы
- Правило «Перед каждым коммитом — gitleaks» сейчас невыполнимо: gitleaks у пользователя `agent` не установлен.
  Снимается отдельной задачей на установку gitleaks (`docs/coordination/COORDINATOR.md`, раздел 8, п. 4).
