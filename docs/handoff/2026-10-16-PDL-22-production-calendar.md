# PDL-22 — разведка: производственный календарь РФ

Задача: PDL-22 «[Работа] Разведка: производственный календарь РФ». План — PDL-21 (разделы «Что сделаю»
1–5), ответы владельца на вопросы плана — в описании PDL-22.

## Что сделано

- `docs/research/2026-10-16-production-calendar.md`:
  - вывод коротко;
  - официальный источник: ст. 112 ТК и постановления № 1466 (2026) и № 1187 (2027); даты
    публикации постановлений за 2023–2027 годы;
  - сверка 2026 года таблицей: isDayOff и Kuzyak совпали с официальным календарём, BasicData
    данных за 2026 год не имеет;
  - сверка 2027 года по открытым файлам Kuzyak и isDayOff;
  - сравнение трёх кандидатов, 4 запасных варианта;
  - рекомендация отдельно от фактов, 3 вопроса владельцу, список источников.

## Что проверено и как

- Тексты постановлений № 1466 и № 1187 прочитаны в PDF с publication.pravo.gov.ru. Даты
  публикации постановлений за 2023–2027 годы взяты из поиска по API портала.
- По одному GET-запросу без ключа к каждому кандидату за 2026 год (2026-10-16 11:10 UTC), всё как
  разрешил владелец:
  - isDayOff `api/getdata?year=2026&cc=ru&pre=1` — 200;
  - Kuzyak `api/calendar/2026` — 200, только сводка по месяцам;
  - BasicData `api/json/calend/` — 200, годы 2003–2017.
- Эталон 2026 и 2027 годов вычислен по ст. 112 и постановлениям. Сравнение со всеми данными сделано
  скриптом вне репозитория: 0 расхождений у isDayOff (365 дней), у файлов Kuzyak за 2026 и 2027 годы и
  у файла isDayOff за 2027 год. Помесячная сводка Kuzyak совпала с эталоном и с КонсультантПлюс (247
  рабочих дней).
- Дни недели ключевых дат проверены через Python `datetime`.
- Звёзды, issues, даты коммитов взяты через `gh api` по публичным репозиториям.
- Строки `docs/REQUIREMENTS.md:103` и `:237` сверены чтением файла.

## Что не проверено

- Даты Kuzyak через сам API (`/holidays`). Второй запрос границы не разрешают, поэтому даты
  сверены по файлам его репозитория. По описанию на сайте API отдаёт эти файлы как есть.
- Есть ли 2027 год в API isDayOff. Страница состава базы показывает годы до 2026, файл 2027 года
  в репозитории есть с 11.10.2026.
- Лимиты и условия использования isDayOff и Kuzyak: на их страницах этого нет.
- Какие изменения ст. 112 ТК ещё не вступили в силу: КонсультантПлюс их отмечает, я не разбирал.
- Проверка на секреты: gitleaks на машине нет, ставить запрещено. Изменены только два документа,
  секретов и персональных данных в них нет — проверено чтением.
