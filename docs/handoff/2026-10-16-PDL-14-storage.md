# PDL-14 — разведка: хранилище данных новой платформы

Задача: PDL-14 «[Работа] Разведка: хранилище данных новой платформы». План — PDL-13 (разделы «Что сделаю» 1–6),
ответы владельца — в описании PDL-14.

## Что сделано

- Отчёт `docs/research/2026-10-16-storage.md`:
  - вывод в начале;
  - карта данных старой системы: таблицы NocoDB и база бота, кто пишет и читает, объёмы;
  - матрица доступа: бот, лендинг, n8n, скрипты, грабер;
  - грабер — по ответам CE, с пометкой «со слов CE, не проверено по коду»;
  - варианты А, Б (основной), В с оценкой;
  - для Б — разделение таблиц: правка / только чтение / не подключать;
  - четыре пути получить каталоги;
  - рекомендация отдельно от фактов;
  - 8 вопросов владельцу.
- Разделение «правка / только чтение» для Б построено на схемах PostgreSQL и правах ролей. В бесплатной
  самостоятельной NocoDB права на таблицы и поля недоступны: по документации NocoDB они только в платных планах
  (ссылки в отчёте, раздел 4).

## Что проверено и как

- Ссылки на код — чтением снимков: `grep -n "NOCODB\|api/v2/tables" bot/main.py bot/bot_registry.py bot/cabinet_service.py`,
  `sed -n` по найденным строкам; номера строк в отчёте сверены повторно.
- Узлы NocoDB в n8n — разбором JSON `n8n/flow/*.json` (тип узла, операция, таблица): 15 узлов в 6 воркфлоу.
- Документация NocoDB (страницы Connect to a Data Source, Field Permissions, Table Permissions) — чтение 16.10.2026;
  лицензия — `LICENSE.md` ветки develop репозитория nocodb/nocodb через `gh api`.
- К NocoDB и сервисам старой системы не подключался; `site_graber` не читал; ничего не устанавливал.

## Что не проверено

- Всё о грабере — только со слов CE грабера.
- Работает ли грабер с NocoDB поверх внешней PostgreSQL (имена колонок, SingleSelect, вложения) — нужна проверка на
  тестовом стенде.
- Как NocoDB хранит SingleSelect и вложения во внешней PostgreSQL — в найденной документации не описано.
- Реальные объёмы таблиц сейчас — только старые цифры из документов (со слов CE кабинета).
- Память и стоимость NocoDB и PostgreSQL под нагрузку — не оценивал; это этап 3.7 «размер сервера».
