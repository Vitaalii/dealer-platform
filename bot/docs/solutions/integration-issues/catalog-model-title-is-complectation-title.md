# «Model title» каталога — не название модели

## Problem

Ответ `GET /cabinet/api/car` собирал `name` из колонки каталога NocoDB
`Model title` (с фолбэком на `Complectation` и `item_name` снапшота). По имени
колонки ожидалось «HAVAL M6» или «MAZDA CX-5», а приходило
«Tech+ 1.5T 150 л.с. AT 4WD» — то есть титул комплектации с двигателем и коробкой,
без модели. В карточке-товаре макета v3, где название — главный текст строки,
клиент не видел, о какой машине речь.

## Root cause

Имя колонки обманывает: `Model title` в каталоге дилера — человекочитаемый титул
**позиции внутри модели**, а не название модели. Модель лежит отдельно, в колонке
`Model`; комплектация — в `Complectation`. То же и в снапшоте: `item_name` — это
комплектационный титул позиции (в дев-БД, например, «Comfort 1.5T 143 л.с. MT 2WD»),
поэтому фолбэк на него давал такой же неполный заголовок.

## Solution

`get_car_card` собирает `name` как «Model · Complectation» (макет v3:
«HAVAL M6 · Family»): части берутся из колонок `Model` и `Complectation` живого ряда
каталога, пустые отбрасываются, разделитель ставится только между двумя
непустыми. Заполнена одна часть — выводится без точки; обе пустые — прежний фолбэк
`Model title` → `item_name` снапшота (лучше неполное имя, чем пустая карточка).
Решение владельца В10 плана `2026-09-26-001`, коммит `38c4501`, покрыто стражами в
`tests/test_cabinet_calc_data.py` (две части, одна часть, обе пустые).

## Prevention

- Имя колонки внешнего каталога — не описание содержимого. Перед тем как подставить
  колонку в пользовательский текст, посмотреть **значения** 2–3 живых рядов, а не
  только заголовок.
- Заголовок для клиента собирать явно из смысловых частей (модель + комплектация),
  а не надеяться на «готовое» поле: у него своя зона ответственности в каталоге и
  оно может меняться независимо.
- Фолбэки выстраивать по убыванию полноты и фиксировать в тестах каждый уровень —
  иначе редкая ветка молча покажет клиенту техстроку.
- Не смешивать поля каталога и поля расчёта: витринная цена `Price new` и цена
  расчёта `credit_price` (`me.calc.price`) — разные величины из разных источников,
  ровно как `Model` и `Model title`.
