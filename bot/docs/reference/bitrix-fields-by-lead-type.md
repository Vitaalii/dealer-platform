# Поля Битрикса по типам заявок

Какие поля сделки и контакта Битрикса заполняются при каждом типе заявки: кто пишет, на каком шаге, откуда значение и перезаписывается ли оно. Полная матрица со всеми подстолбцами — в `bitrix-fields-by-lead-type.xlsx` (лист «Матрица»).

- Источник — код бота v3.4.1 (ветка feat/cabinet-web-entry, 9f5c185; код = тег v3.4.1) живые сделки 53347 (веб-вход, комбо) и 53345 (чат, in_progress), Tilda-сделки дилеров 01/02/03/99 и скриншоты интеграции Tilda → Битрикс — всё прочитано 07.10.2026. Персональные данные — «заполнено».
- * «нет сценария» — наличие, консультация, отказ, другая модель (в коде нет сценария «не определён»; отказ и другая модель ведут в C9:LOSE и без карточки дилеру).
- † 3г и 3д добавлены по коду: они тоже пишут в сделку.
- 5Б — только создание сделки; дальше анкета или таймаут идут как 5К / 5Т / 5С / 5Х. 5Х (таймаут) пишет госномер и пробег с лендинга, но не анкету.
- Тип 1 включает два финала воронки: ветка А — передача Александру (дальше тип 3 или 4), ветка Б — конверсия без ИИ. Тип 7 — то же, но сделка Tilda по коду не найдена.
- Коды F_* и стадии STAGE_* — из .env дева; значения боя не читались (лист «Неподтверждённое»).
- Колонка Tilda — по скриншотам профиля «Заявка из Tilda» (07.10.2026); коды, обрезанные на скриншотах, сопоставлены по названию через crm.deal.fields (все 30 — однозначно, совпадают с cabinet_web_deal_map.json). Проверено на 24 Tilda-сделках дилеров 01/02/03/99.

## Обозначения

| Отметка | Смысл |
|---|---|
| `T` | пишет Tilda: переменная, cookie или заголовок есть в профиле «Заявка из Tilda» (скриншоты 07.10.2026) |
| `T∅` | переменная есть в профиле, но эта форма её не передаёт — приходит пустой |
| `Б` | пишет бот при создании сделки или контакта |
| `Б↻` | бот перезаписывает поле |
| `Б+` | бот добавляет: комментарий в ленту, телефон в контакт |
| `n8n↻` | бот пишет значение из ai_payload Александра (перезапись, если ключ непустой) |
| `n8n?` | refuse/ban: полный ai_payload только через finalize_deal; bypass передаёт лишь status и report |
| `Б(слот)` | бот пишет из слотов оценки трейд-ина (диалог с Александром); в колбэке — только если ключ пуст в ai_payload |
| `?` | кто пишет, не видно ни в коде бота, ни в профиле Tilda — не подтверждено (вероятно роботы воронки) |
| `—` | на этом типе заявки поле не пишется |
