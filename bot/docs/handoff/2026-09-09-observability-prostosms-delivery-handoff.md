## 3. Решения владельца (переживают сессию, дословно)

- **Р1** — критерий паритета: извлечение находит всё, что признаёт
  `is_valid_phone`.

  KTD-8): `payload_v2.py:48` `PHONE_GROUP_PATTERNS`.
- **Р10** — `phone_collected` ставится только при успешной записи.
- **Р11** — повтор перед алертом, пауза 90 с
  (`cabinet_service.py:225` `_alert_retry_delay`, env `CABINET_ALERT_RETRY_DELAY`).
- **Р12** — дедупликация 6 ч, эскалация после 3
  (`cabinet_service.py:209` `ALERT_DEDUP_WINDOW_SECONDS`, `ALERT_ESCALATE_AFTER`).

- **B-2** — env-выключатель не нужен, откат — revert коммита.
- Нормализация госномера у нас — только воронковый слот
  (`payload_v2.py:170` `normalize_plate_input`); основная правка — в
  инструменте оценки на стороне n8n.

## 4. Установленные факты (дорогие для повторного добывания)

- **Инцидент 51365** [факт]: номер «8/980/555-28-17» не извлекался старым
  PHONE_RE; барьер Р4 отработал по спецификации — дефект был в извлекателе,
  не в барьере.
- **Класс ложных срабатываний «денежные пары»** [факт]: «800 000, 30 000»
  склеивались в валидный 11-значный номер; закрыт белым списком
  разрядностей (Р9). Живые случаи из архива NocoDB: «Е259РХ37 120000»,
  «Н864СМ37, 220000».
- **Поля трейд-ина не писались на 4 путях завершения из 6** [факт]:
  причина на сабмит-пути — фронт кабинета показывает read-only карточку
  «Ваш автомобиль» вместо полей ввода, когда `found_info` уже есть;
  None из формы в CRM не уходил. Решение: две точки записи
  (`main.py:1138` `build_ai_tradein_fields` + снапшот-фолбэк в
  `cabinet_service.push_form_to_bitrix`). Урок:
  `docs/solutions/logic-errors/ai-fields-only-on-ai-payload-paths.md`.
- **Ловушка R34** [факт]: `submitted_at` ставится ДО конверсии, поэтому
  один общий хелпер не мог записать SB-поля на сабмит-пути (фильтр
  `filter_cabinet_owned_fields` дропал бы их). Решение — две точки записи.
- **Инцидент ProstoSMS 627 ЗАКРЫТ** [факт, ответ поддержки провайдера
  2026-09-08]: виновный адрес **202.133.219.44** — не принадлежит ни
  подсети Dockhost 45.92.179.192/28, ни зарубежному 103.112.69.233.
  Провайдер пересохранил запись 2026-09-08 («должна решиться», не
  «решена»). Наблюдение второй день — тихо. Аккаунт A-42189,
  ключ Ufno…1f5d (64 симв.).
- **Внешний адрес изнутри контейнера определить НЕВОЗМОЖНО** [факт]:
  у контейнера Dockhost два исходящих канала (РФ 45.92.179.192/28 и
  зарубежный), выбор по направлению трафика; локальный адрес соединения

  traceroute в образе нет; эхо-сервисы отвечают про дорогу к себе
  (api.ipify.org за Cloudflare → всегда зарубежная дорога). Рабочий путь
  диагностики — access-логи получателя. Урок:
  `docs/solutions/logic-errors/egress-ip-depends-on-destination.md`.
- **Три опровергнутые версии по дороге к диагнозу** [факт] — не повторять:
