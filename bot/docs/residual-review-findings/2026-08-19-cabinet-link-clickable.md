## Принятые остаточные риски (зафиксированы, действий не требуют)

- Два независимых запроса URL за ход (история + отправка): при ротации токена
  в этом окне история может разойтись с отправленным текстом — следствие КТР-5.
- `get_active_cabinet_url` не проверяет `expires_at` (зеркалит issue-ветку):
  между истечением и свипом воркера клик даст `link_expired`.
- Маркер внутри блока `<function_calls>` аварийного моста: клиент текст не
  видит (блок вырезан), но нормализация истории подставит URL внутрь
  технического блока — n8n увидит URL, которого не было в диалоге.
- `[SPLIT]` внутри анкора расширенной формы: ссылка и разрез выживают, но во
  вторую часть утекает хвост `…]`.
- Страховка ловит только точные вхождения — немо искажённый моделью URL
  необнаружим (класс ошибок закрыт маркером, не страховкой).
- Виджет линкифицирует любую https-ссылку строгой формы, не только домен
  кабинета — фишинг через prompt-injection ограничен https-only и собственной
  сессией (принято планом).
- Source-grep-стражи wiring (`TestWiring`) хрупки к рефакторингу main.py —
  компенсировано интеграционными тестами `test_cabinet_link_wiring.py`.
